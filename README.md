# Boltverse Odyssey Mobile — phone play copy
Phone-web play copy of Odyssey: Grok Bot connector top-right, Citadel Door only in the picker, music under Howl in the left rail.

## Run

Use the existing Vite script. Serves on port 8080. No API keys.
Wake URLs, keys, and live session files stay local. Only helper scripts and live/wakes/README.txt belong in git.
